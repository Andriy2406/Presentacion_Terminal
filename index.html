Terminal integrada

Terminal dentro de IntelliJ y comandos básicos

Aprendiz: Jhostin Andriy Guzman Rojas

¿Qué es la terminal integrada?

  • Una consola de comandos dentro del mismo IntelliJ IDEA.
  • No hay que abrir otra ventana (CMD, PowerShell, etc.).
  • Se abre ya ubicada en la carpeta de tu proyecto.
  • Sirve para compilar, ejecutar, usar Git y Maven sin salir del IDE.

¿Cómo la abro?

  • Atajo: Alt + F12
  • Menú: View → Tool Windows → Terminal
  • Botón Terminal en la barra inferior izquierda
  • Botón ＋ = abrir más pestañas de terminal
  • Puedes elegir el shell: PowerShell, CMD, Git Bash…

Comandos básicos

pwd / cdVer dónde estoy / cambiar de carpeta
dir (ls)Listar archivos
mkdir carpetaCrear una carpeta
cls (clear)Limpiar la pantalla
java -versionVer la versión de Java
javac / javaCompilar y ejecutar
git statusVer cambios en Git
mvn -vRevisar Maven

Ejemplo práctico

PS C:\Proyecto\src> javac HolaMundo.java
(compila, sin errores)
PS C:\Proyecto\src> java HolaMundo
¡Hola Mundo!

Compilamos con javac y ejecutamos con java. ¡Todo dentro de IntelliJ!

Errores comunes y solución

  • "javac no se reconoce" → falta configurar el JDK en el PATH / JAVA_HOME.
  • "No se encontró la clase" → estás en la carpeta equivocada; usa cd.
  • Comando no funciona → mal shell (CMD vs PowerShell); cambia en Settings → Tools → Terminal.

¡Resumen!

  • La terminal integrada = consola dentro del IDE
  • Se abre con Alt+F12
  • Comandos clave: cd, dir, javac, java, git
